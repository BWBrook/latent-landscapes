The immutable `design-freeze.md`, `panel-manifest.json` and `freeze.json`
record the independently reviewed design and identities before selected
outcomes or fits. `source/` contains pre-panel versions preserved to explain
inherited receipt bindings; the reviewed implementation is in the Git commit.
The 335-test local log and independently reviewed importance smoke are retained.
The smoke uses an already inspected H3 history solely to measure runtime.

Bulk panel fits, evaluation streams and generated inputs are archived under
`nectar:/data/share/latent-landscapes/`. Compact result manifests and hashes
will be added here after execution and independent review. This package is
synthetic development, with no calibration or production-readiness claim.

## Standard and roles

**Threat model.** This protects the capstone's realised truth and held-out
observations against *accidental* exposure to honest agents. It does not
protect against deliberate circumvention by an agent with shell access on the
shared account. The paper should state this standard.

- **Barry** creates the key, keeps its passphrase in his password manager and
  runs the two release commands. Only Barry ever types the passphrase.
- **Fable** receives only the public key. Fable runs the sealed generation and
  never sees the truth either.
- **Astra** analyses the training package blind and receives the held-out
  observations and the truth only at the two release points.

Never paste the passphrase or the contents of the identity file into any chat,
correspondence message or agent-run shell. Run every command below in the macOS
**Terminal** app. Do not use the terminal panel inside the Claude desktop app,
because Claude can read that panel, and do not use a shell that Codex runs.

## One-time key creation (Barry, about five minutes)

1. Install the encryption tool:

   ```bash
   brew install age
   ```

2. Make a private folder and create a passphrase-protected key in it:

   ```bash
   mkdir -p ~/Private/latent-landscapes-capstone
   cd ~/Private/latent-landscapes-capstone
   age-keygen | age -p -o capstone-identity.age
   ```

   The terminal prints `Public key: age1...`, then asks for a passphrase. Paste
   a long passphrase generated by your password manager, or press Return and let
   `age` generate one, which it then prints. Either way, save the passphrase in
   the password manager.

3. In the same password-manager item, also store the `age1...` public key and,
   as an attachment, the file `capstone-identity.age`. That file is encrypted
   with the passphrase, so keeping a copy in the private folder is also safe.

4. Check the whole chain once. Replace `<public-key>` with your full public key,
   the long string beginning `age1` that step 2 printed:

   ```bash
   echo "custody test" | age -r <public-key> | age -d -i capstone-identity.age
   ```

   Enter the passphrase when asked. The command should print `custody test`.
   An error saying `malformed recipient` means the placeholder was not replaced.

5. Send Fable the `age1...` public key in Claude chat. That is the only thing
   either agent receives. Then close the Terminal window.

## What Fable's generation will do

Generation happens only after the calibration route and the four-case union cap
are frozen. One process will:

- draw private seeds from operating-system entropy and never print them;
- build the truth bundle and the held-out package in memory, each including a
  32-byte random salt, so their hashes cannot be guessed from the small number
  of plausible truths;
- publish the SHA-256 of each plaintext package as its commitment, and the
  SHA-256 of each encrypted file;
- write those two packages only as files encrypted to Barry's public key, and
  write the training package in plain text;
- print only file names, sizes and hashes, so no truth value enters any log or
  transcript.

## If something goes wrong

- **Passphrase lost:** the truth cannot be recovered and the capstone cannot be
  audited. Keep the password-manager item backed up.
- **Early decryption by mistake:** do not share the output. Record what
  happened, and the reveal record will report it.
- **Agent sees a secret by mistake:** stop, record it, and decide with Barry
  whether to regenerate under a new key before analysis begins.

## Primary detector

For every candidate g, process each original calibration history through its
own training fit and held-out conditional prey score S*. For observed S, use
`p_g=(1+count[S*_g<=S])/1000` with inclusive ties. Derive an auxiliary C99 from
the 990th of 999 original candidate-specific LR scores. It is separate from
the unchanged Goal 049 rank950 effect set. Report
`p_BB=min(1,max_{g in C99}p_g+0.01)`; reject the composite assumed-model adequacy null (flag model inadequacy)
at p_BB<=0.05.
Use every candidate in C99 on the full original grid. No smoothing, interpolation,
subset shortcuts or plug-in replacement. Require nonempty C99 containing a
training maximizer.

The confidence-set union bound permits C99 and p_g to share the reference
histories; resampling must preserve this dependence. The fixed-procedure guarantee
is marginal over reference histories and new histories, conditional on a fixed
independent bank, on the finite grid under the assumed known-nuisance generator.
It is not conditional size control for one realised table or a universal claim
about a method selected after retrospective exploration. Existing six-truth
operating characteristics are labelled retrospective; fresh null evaluation is
prospective after this registration. No alternative-generator detector power is
measured by this tranche. The secondary predator statistic cannot trigger the
primary decision and is not combined into an omnibus test.

## Null-block diagnostic and uncertainty

Cross the original and fresh rank950 null cutoffs with original and fresh null
evaluation blocks. Report all four counts, both cutoffs, paired changes within
each evaluation block and the interaction/difference of those paired changes.
Use the original reference detector on fresh null evaluation as well. Do not
replace the original table whatever the diagnostic shows, and do not assign a
unique cause from the four dependent cells alone.

Report primary detector rejection rates, C99 inclusion and original effect-set
null exclusion across all six retrospective truths and fresh null evaluation.
Conditional Wilson 95% intervals hold tables fixed. Separately perform exactly
1,000 calibration-aware bootstrap draws with RNG root 2026092006: independently
resample original calibration, fresh null calibration, original evaluation and
fresh null evaluation replicate blocks. Original calibration weights are shared
across all candidates and between LR/reference-score quantities; original
evaluation weights are shared across six paired truths. Within each draw,
recompute weighted rank990/rank950 cutoffs and reference-score ranks. This is
empirical uncertainty, not an additional exact coverage theorem. Preserve
pairing for crossed contrasts. Constant bootstrap series have exactly zero SE;
undefined ratios are not silently set to zero. No refinement after seeing CIs.

A low realised rejection rate does not prove useful detector power. A high one
is reported and checked mechanically, not repaired with a different statistic.
The scientific endpoint is a qualified implementation and honest baseline,
including a negative or conservative result. Predictions are descriptive, not
acceptance gates: the confidence-set supremum may be conservative; crossed
null blocks may localise sensitivity but may remain ambiguous.

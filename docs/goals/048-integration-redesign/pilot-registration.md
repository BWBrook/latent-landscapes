# Goal 048 bounded developmental screen

Registered before evaluating the new conditional integrator on returned banks.
This screen diagnoses feasibility; it cannot qualify a replacement for Goal 046.

The first full-map screen uses global Gamma conditioning of existing exponential
edge draws. For each of connected/corridor map 2026090812, use the first 256
and first 1024 draws from each disjoint Goal 047 half-bank. Recover the radial
sum from the original bank seed and exact edge count, without regenerating
shortest paths. Conditional shape is the number of independent undirected
edges; conditional site scale is original arrival divided by that radial sum.
No pseudocount or probability floor is permitted.

Inspect all seven arrival-category probabilities at rho=1 for connected and
the eight registered Goal 047 rho nodes for corridor. Generate only connected
calibration histories 124 and 131 and evaluation history 231, plus corridor
evaluation history 0 (zero-based indices). Retain both designs for connected
and access for corridor. These histories are explicitly selected from the
previous failures and are retrospective stress controls.

Before spending on H181 survival integration or generating new QMC directions,
check whether floating-point category integration supplies every observed
predator-history marginal with positive finite mass. Compute each interval
using the better-conditioned CDF or survival-function difference. Report
underflow and missing support explicitly; never patch them with epsilon.
Failure requires either a justified logarithmic implementation or a different
conditional representation before likelihood evaluation. It is a numerical
implementation obstacle, not proof that the mathematical estimator is biased.

Exact controls precede any method recommendation: exponential/Erlang paths,
a diamond with two independent Erlang paths, and exhaustive jump-chain mixing
versus the full infected-set continuous-time Markov chain. Compare category
masses and prey survival moments on the actual six survey times, rho values
0.5/1/2 and effect values 1/3/5. Target absolute error is 1e-10 for ordinary
probabilities and relative error 1e-10 for analytically tractable small tails.

Use local short computations only for this support screen, with at most 1024
existing directions per map/half and no new full-map bank generation. Stronger
full-map likelihood or QMC experiments require a written bounded execution
plan informed by this result, within Goal 048's approved development scope.

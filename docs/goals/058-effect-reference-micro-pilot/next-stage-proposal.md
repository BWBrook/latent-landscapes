## One public screen experiment

Freeze the 17 x 9 x 5 support, .25 beta neighbours, existing local discrepancy,
inclusive ties/ranks and q>.01 rule before generating **99 fresh pre-only
references per node: 75,735 total**. Use the same .25 neighbourhood for each
observed history and each reference; subsetting the old Goal 057 ranks cannot
replace this recalibration. Freeze an unused RNG namespace/root before any
draw and use a separate mechanical root for qualification.

Use the existing sixteen open Goal 056 histories as a descriptive retention
panel. Report every retained set and all 1,820 four-case unions, including
empty sets, failures and cap implications. Report true-node retention only
where the original truth is on the new support; preserve and explicitly label
the beta=.6 histories as off-grid. This panel helped motivate the design, so
fresh reference streams do not turn its ranks into a prospective coverage or
false-declaration experiment. No true value is rounded or replaced.

Reuse the established pre-only likelihood and independent reconstruction.
Check observation scores, local discrepancies, ranks, table completeness and
all unions independently, with reference score/replay checks defined before
launch. Preserve failed references; an unavailable screen cannot produce a
favourably reduced set. Report all results even if retention fails to shrink.
There is no search across alternative screening statistics or thresholds.

Proposed envelope: **eight workers, one numerical-library thread each,
16 GiB aggregate RSS and one hour**, including numerical checks. The old
3,645-node screen plus 792 diagnostic fits finished in 6.62 minutes on eight
workers. This proposal has 21.0% as many screening references and no new
diagnostic-fit panel. That is a workload comparison, not a runtime guarantee;
target qualification must confirm the envelope. A numerical or resource stop
preserves the attempt and requires diagnosis before any registered restart.

This tranche's deliverable is measured coarse-grid retention and a costed
resource decision. It authorizes neither 999-reference effect tables at the
retained union nor operating-rate evaluation, a new map, or sealed generation.

## Later effect-table budget and claim

The current 268-node old-mask proxy would imply about **33.1 hours** if the
observed 16-production/4-audit allocation scaled unchanged. With hypothetical
64-worker scaling in both stages it gives **6.39 hours**, or **9.59 hours**
with a 1.5 margin. The 163-node R<=10 proxy gives 20.1, 3.89 and 5.83 hours
respectively. None is an observed coarse-screen union or a runtime bound.
The full 765-node effect table projects to 94.5 hours under the observed
allocation, or 27.4 hours under the 64-worker arithmetic with margin.

Use the measured new union distribution and a target-host qualification to
choose a resource cap before confirmatory observations. The cap applies to
the complete required union across all four cases before dispatch; exceedance
means abstention. Missing/invalid tables must also abstain. Zero failures in
the four pilot tables does not justify relaxing that rule or assuming zero
failures elsewhere. Multi-node compute remains an option if the actual
workload warrants it, not an assumed 64-core speedup.

## Freeze the final truth law before confirmatory evidence

The approved support does not yet specify the sealed truth distribution.
The earlier capstone mixture contains an E06 beta=.6 branch and a B100-A
residual-field branch. The former is off the new grid; the latter is outside
the exact family. Fable and Barry need to settle whether and how to replace
the former and whether to retain the latter as an explicitly separate stress
case, with its claim and mixture weights stated. Four histories and Barry's
existing key custody remain the accepted framework. This proposal makes no
replacement choice and accesses no private key or sealed truth.

Recommendation: retain Goal 058 reference banks as open design evidence.
Freeze the final truth distribution, map/design, full testing rule,
multiplicity treatment, failure policy and union cap before generating fresh,
independently addressed confirmatory reference banks and sealed observations.
Chronologically earlier references can be valid for a genuinely bank-independent
fixed test/truth law; the problem is selecting those choices using the
realised reference tails or failures. Unseen observations alone do not remove
that dependence. Do not pool the pilot banks into the primary confirmatory
ranks after using them to select the final design. Fresh streams also do not
extend an exact-family argument to a residual-field or off-grid stress case.

The next public screen experiment can proceed after review without deciding
the final truth mixture. Its scope remains descriptive design evidence. A
separate, explicit final-design decision precedes large confirmatory work.
